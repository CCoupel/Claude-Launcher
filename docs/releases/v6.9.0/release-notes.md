# Release v6.9.0 - Le bon modèle pour chaque teammate

**Date** : à renseigner à la publication

## Nouveautés

### Modèle et effort réglables depuis la carte TEAM
Un clic sur la colonne modèle ou effort de la carte TEAM ouvre un menu (fenêtre native) ; dans la coque tmux, un clic ouvre un menu tmux. Vous choisissez le modèle et l'effort du teamleader ou d'un teammate sans éditer de fichier.

- Le réglage est écrit dans le compagnon du projet et prend effet au prochain démarrage du teammate (⟳ tant qu'il tourne avec une autre valeur).
- « Défaut (template) » retire votre surcharge.
- Un effort non pris en charge par le modèle choisi est grisé.
- Sécurité : le réglage est refusé depuis un accès web distant ; seule la fenêtre native peut le modifier.

## Comment mettre à jour

Remplacez le binaire puis utilisez le bandeau « binaire changé → Relancer » (`ctrl+r` dans la coque).
