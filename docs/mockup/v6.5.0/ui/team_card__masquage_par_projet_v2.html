Carte TEAM — œil du masquage, v2 · #209 · v6.5.0 · maquette retenue (A — Bouton enfoncé)

Cette maquette reprend la maquette validée v6.5.0/ui/team_card__masquage_par_projet.html et la remplace, avec trois changements demandés par l'utilisateur. (1) La puce « masquage 30 s » est supprimée : l'œil suffit. (2) L'œil est aligné à droite de la ligne de titre (les versions se tronquent avant lui). (3) Le mode default (suit le réglage global) se distingue nettement d'un choix du projet (auto hide / no hide). Point 3 retenu : bouton enfoncé. Le reste est inchangé : œil ouvert = no hide, fermé = auto hide ; clic = default → auto hide → no hide → default ; clic droit = menu ; infobulle avec la valeur globale.

Parti pris retenu — A — Bouton enfoncé (forme et fond). Un choix du projet affiche l'œil sur un fond plein bleu (bouton « enfoncé », icône sombre). En default, l'œil est gris, nu, sans fond. Avantage : la différence se voit de loin, et la convention « bouton activé = réglage propre » est familière. L'ouvert / fermé reste lisible dans les deux cas. Inconvénient : c'est l'élément le plus voyant du titre quand un projet a son propre choix.

Règles

  • Plus de puce « masquage N s » dans le titre de la carte TEAM : le délai est donné par l'infobulle de l'œil.
  • L'œil est le dernier élément de la ligne de titre, collé à droite. Si la place manque, ce sont les versions qui se tronquent (…), jamais l'œil.
  • Œil ouvert = no hide ; fermé = auto hide ; default = dessin de l'effet global (fermé si le global masque, ouvert sinon), toujours en gris.
  • Choix du projet (auto hide / no hide) : œil sur fond plein bleu (accent), icône sombre ; survol : bleu plus clair. default : œil gris, sans fond.
  • Infobulle : « Ce projet : <état> — clic : <suivant> · réglage global : masqués après 30 s | désactivé ».
  • Le menu du clic droit reprend le même rendu d'œil pour chaque choix.
  • Coque Linux (pas d'œil, affichage seul) : le titre se termine par « · default (masqués 30 s) » / « · default (désactivé) », ou par « · auto hide » / « · no hide » suivi de la marque du projet ◆.
  • Inchangé : versions dans le titre, ⚠ orange en bout de ligne de teammate, « modèle · effort » sur chaque ligne.
