Carte TEAM — masquage des inactifs par projet · #209 · v6.5.0 · maquette retenue (C — Icône œil, ajustée)

Composant : carte Team du volet d'état (interface native Windows ; coque Linux en affichage seul). Une icône œil au bout du titre porte le réglage du projet, en trois états : ouvert = no hide (les teammates restent toujours visibles dans ce projet), fermé = auto hide (les inactifs sont masqués dans ce projet), grisé = default (le projet suit le réglage global #188). Le réglage est persistant (PROJECT_HIDE_IDLE) et appliqué sans relance. Le reste de la carte est inchangé (maquette v6.2.0 complétée). Exemple : global activé, délai de 30 s.

Parti pris retenu : la solution la plus compacte (≈ 22 px dans le titre). Le dessin de l'œil donne l'état du projet, et le grisé signale qu'il suit le global. Interaction : un clic fait défiler les trois états, dans l'ordre default → auto hide → no hide → default. L'infobulle annonce l'état courant, le suivant et la valeur globale. Un clic droit ouvre un menu pour choisir directement un état, sans tout faire défiler. Clavier : l'icône prend le focus, Entrée ou Espace font comme le clic, et la touche Menu fait comme le clic droit.

Règles

  • Œil ouvert (couleur du texte) = no hide : rien n'est masqué automatiquement dans ce projet ; PROJECT_HIDE_IDLE[projet]=none.
  • Œil fermé (couleur du texte) = auto hide : inactifs masqués après le délai global (TEAM_HIDE_IDLE) ; =auto.
  • Œil grisé = default : aucune entrée, le projet suit TEAM_HIDE_IDLE_ENABLED. Son dessin montre l'effet du global : grisé fermé si le global masque, grisé ouvert sinon.
  • Clic : default → auto hide → no hide → default. L'écriture se fait au clic (projectApply {hideIdle}) et la carte se met à jour aussitôt. Pendant l'écriture, l'icône est en attente (pas de second clic) ; en cas d'échec, l'état précédent revient et un message court s'affiche.
  • Clic droit : menu « Teammates inactifs » à trois choix ; le choix courant est en surbrillance, et le choix default donne la valeur globale.
  • Infobulle : « Ce projet : <état> — clic : <suivant> · réglage global : masqués après 30 s » (ou « réglage global : désactivé »).
  • Puce « masquage 30 s » : présente quand le masquage s'applique effectivement au projet (auto hide, ou default avec le global activé), absente sinon. Elle est placée avant l'œil.
  • Changer le global ne touche que les projets en default ; les choix auto hide / no hide sont conservés.
  • En no hide : aucun teammate n'est masqué. Le double-clic sur une ligne pour cacher un teammate est refusé, avec le message « masquage désactivé pour ce projet : choisir « auto hide » dans le titre de la carte TEAM ».
  • Coque Linux : le titre affiche l'état effectif (« masquage 30 s » ou « no hide »), suivi de « · projet » si le projet a son propre choix.
  • Inchangé : versions dans le titre, ⚠ orange en bout de ligne, « modèle · effort » sur chaque ligne, surbrillance du pane visible.
