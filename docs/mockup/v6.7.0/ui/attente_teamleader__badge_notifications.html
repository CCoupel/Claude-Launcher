Maquette #223 — teamleader en attente de réponse : badge, vignette et notifications (v6.7.0) · maquette retenue (A — Pastille « ❓ en attente »)

Quand le teamleader d'un projet pose une question (AskUserQuestion, dont les GATE) ou attend une permission, le launcher le signale sur toutes les interfaces ouvertes (fenêtre native Windows, navigateur --web, coque tmux Linux) en moins de 5 s, et le signal disparaît dès la réponse. Scène commune : trois projets ouverts ; le teamleader de web-shop pose la question « Valider le plan v2.3.0 ? » ; Claude-Launcher est le projet sélectionné. Les notifications (Windows et navigateur) sont désactivables dans Réglages. Les éléments inchangés (indicateurs de l'arbre, couleurs des onglets, cartes) restent tels qu'aujourd'hui.

Règles communes (toutes propositions)

  • Attente signalée (décision GATE 2) : question AskUserQuestion (dont les GATE) et demande de permission du teamleader seulement ; jamais d'un teammate.
  • Le signal disparaît dès la réponse (question répondue, permission accordée ou refusée, nouveau message tapé, fin de session ou pane disparu).
  • Détection par hooks Claude Code posés par le launcher : délai ≤ 5 s sur toutes les interfaces, y compris pour un projet en pod (état écrit dans le dossier du projet, partagé).
  • Une seule notification par attente et par interface (même attente revue au tour suivant : pas de nouvelle notification) ; aucune après la réponse.
  • Clic sur la notification : la fenêtre passe au premier plan et l'onglet du projet est sélectionné.
  • Notifications activées par défaut (désactivables dans Réglages › Teams et panes). Navigateur : l'autorisation est demandée par un bandeau « Autoriser les notifications d'attente » (clic requis par le navigateur), affiché tant qu'elle n'est ni accordée ni refusée ; refusée ou adresse http hors poste local (contexte non sécurisé) → badge seul, mention dans Réglages.
  • Teamleaders : jamais de compteur ni d'icône seule permanente sur la pastille (contrainte tab_bar).
  • Projet non ouvert dans cette interface mais dont la session tourne (autre launcher, pod) : signalé dans l'arbre aussi.
