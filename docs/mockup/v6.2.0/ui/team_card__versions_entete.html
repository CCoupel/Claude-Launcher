Carte TEAM — versions en en-tête · #151 · v6.2.0 · maquette retenue (A — Versions dans le titre)

Composant : carte Team du volet d'état, interface native Windows et coque Linux. Aujourd'hui chaque ligne porte une ou plusieurs versions (version de claude sous Windows ; version du template et de claude sous Linux), ce qui élargit la carte. Les versions ne sont plus affichées qu'une fois, dans l'en-tête ; un teammate dont une version diffère de celle de l'en-tête porte un ⚠ orange. Tout le reste de la carte (surbrillance du pane visible, double-clic caché ↔ visible, + du compagnon, ○ non démarré) est inchangé — maquette v6.1.0 complétée. Exemple : test-writer a un template en retard (v5.9.2), qa tourne avec un autre claude (2.1.85).

Parti pris : les deux versions rejoignent le titre de la carte ; les lignes gardent « modèle · effort » et un ⚠ en bout de ligne. Avantage : rien n'est perdu à la lecture, une seule colonne retirée. Inconvénient : gain de largeur modéré ; le titre est long (il se tronque en dernier sur la version de claude).

Règles

  • Version du template de l'en-tête : la version cible du projet (celle que le launcher a adoptée). Version de claude de l'en-tête : celle du leader.
  • ⚠ orange : le template du teammate n'est pas à la version de l'en-tête, ou son claude n'est pas celui de l'en-tête. L'infobulle (Windows) ou la ligne (Linux, pane large) dit lequel et donne la version.
  • Le ⚠ remplace le ▲ de la v6.1.0 (un seul signe pour « pas conforme »). ● démarré et conforme, ○ non démarré.
  • Un teammate non démarré est comparé sur son template seulement (il n'a pas de claude).
  • Version cible inconnue (projet sans registre d'agents) : pas de version de template dans l'en-tête, aucun ⚠ pour le template.
  • Inchangé : surbrillance = pane visible ; double-clic = caché ↔ visible ; + = fichier compagnon ; états et délais dans l'infobulle.
