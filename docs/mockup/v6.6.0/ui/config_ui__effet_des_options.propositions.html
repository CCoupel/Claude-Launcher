Maquette #226 — page de config : ce qu'il faut pour qu'une option prenne effet (v6.6.0)

Chaque option de la page Réglages indique quand elle prend effet : ● immédiat ⟳ réouverture du projet ✳ relance des sessions claude ↻ relance du launcher. Après l'enregistrement, un rappel liste les actions nécessaires pour les options modifiées (et propose « Relancer le launcher », #219). Effets établis après #225 (config relue à chaud, settings.json recopié à l'enregistrement). Rubrique « Launcher » (maquette active v6.1.0/ui/config_ui__interface_structuree.html) ; web et fenêtre native ; coque : mention texte sous chaque proposition.
