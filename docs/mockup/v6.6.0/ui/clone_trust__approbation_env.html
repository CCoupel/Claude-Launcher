Maquette #215 (amendement) — approbation de l'environnement d'un projet cloné (v6.6.0)

Un projet cloné qui apporte .claude-launcher/env.yaml ou env-template.yaml est « non approuvé ». À sa première ouverture dans un conteneur, le launcher montre ce que le dépôt demande — image, paquets, commandes setup / on_start, montages — et demande Accepter / Ouvrir sans (environnement du dépôt ignoré : seul le socle choisi à la création est gardé) / Annuler. Le choix est mémorisé côté launcher (jamais dans le projet) et définitif : un pull qui modifie ensuite ces fichiers ne redemande pas (le choix se revoit dans ⚙ Réglages du projet → « Revoir »). Web et fenêtre native : même dialogue ; coque tmux dessous. Exemple : CCoupel/supervision-k8s.
