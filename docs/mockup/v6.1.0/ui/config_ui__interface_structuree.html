Interface structurée de configuration · #118 · v6.1.0 · interface native Windows · maquette retenue (A — Fenêtre Réglages à rubriques)

Composant : gestion de la configuration du launcher dans l'interface native (Windows ; le mode --web sert la même interface au navigateur, pour les tests). La maquette est navigable : cliquer sur les rubriques, sur les boutons « Écran » au-dessus de la fenêtre (menu contextuel d'un projet, réglages du projet). Une seule fenêtre « Réglages » (modale large, ouverte par ⚙ config ou Ctrl+,, à la place de l'éditeur de texte actuel qui reste accessible par « Éditer en texte ») ; le menu contextuel d'un projet ouvre cette même fenêtre sur la rubrique du projet.

Règles communes

Enregistrer réécrit le fichier en conservant ses commentaires et passe par la même validation que le chargement réel : les problèmes s'affichent en bas de l'écran, une erreur bloque l'enregistrement. « Éditer en texte » ouvre l'éditeur de texte actuel sur le fichier de la rubrique. Les changements sont appliqués à chaud quand c'est possible (même note qu'aujourd'hui sinon). Si le fichier a changé sur disque entre-temps, l'enregistrement le signale (recharger / écraser), comme l'éditeur actuel. Le jeton GitHub est masqué. Changer le backend d'un projet ouvert est refusé avec un message (fermer d'abord), comme F2 aujourd'hui.
